# Kairos for iPhone

The native SwiftUI companion to the Kairos desktop app. It syncs over the local network from the desktop's LAN bridge (`../sync_server.py`).

## Layout

```
ios/
  Package.swift          SwiftPM: KairosCore, KairosUI (+ MapLibre Native), KairosCoreTests
  project.yml            XcodeGen spec for the iOS app target (KairosApp)
  KairosApp/             @main entry, injects AppModel, shows RootTabView
  KairosCore/            no UI: models, replica DB, sync, edit math
    Models/              MediaItem, Event, Person, Face, Album, EditRecord, Adjustments, JSONValue
    Database/            SQLiteDatabase (SQLite3 C-bridge, GRDB-shaped API), LibraryStore (replica)
    Sync/                WireProtocol, SyncClient (+ PinnedTrust, Keychain), SyncEngine (actor)
    Imaging/             EditMath (port of quick_edit.py), EditPipeline (CoreGraphics + vImage,
                         geometry and tone passes), CropGeometry (port of the desktop crop tool)
    Geo/                 PinClustering (port of the desktop map's clustering + teardrop pin)
    Tests/               ContractTests, Phase2ContractTests + Fixtures generated by
                         ../test_ios_sync.py and ../test_ios_phase2_contract.py
  KairosUI/              SwiftUI
    Theme/Tokens.swift   desktop palette (#05060B, #1C1C1E, Iris #8B93FF), radius, space, motion
    Root/                AppModel (@Observable), RootTabView (5 tabs), SyncBadge
    Viewer/              UIPageViewController pager + ZoomingImageView (pinch to 400 %, double-tap
                         Fit <-> 1:1, rubber band, 1:1 detail pass)
    Edit/                EditView (tone tools, live preview), CropStraightenView (drag/pinch crop,
                         aspect presets, straighten dial), EditRenderer (coalesced off-main preview)
    Map/                 MapLibre over Documents/*.mbtiles, desktop teardrop pins (PinImageRenderer)
    Library/ Events/ People/ Search/ Pairing/ Components/
  docs/SYNC_PROTOCOL.md  wire protocol 1
```

## Build (macOS with Xcode 15.3+ / Swift 5.10+)

```sh
cd ios
swift test                         # KairosCore contract tests (no simulator needed)
brew install xcodegen && xcodegen  # -> Kairos.xcodeproj
open Kairos.xcodeproj              # run the "Kairos" scheme on an iPhone (iOS 18+)
```

## Build without a Mac (GitHub Actions + Sideloadly)

`.github/workflows/ios.yml` runs on a GitHub macOS runner for every push or PR to `main` that touches `ios/**`, and on demand (Actions › iOS › Run workflow). It runs the KairosCore contract tests on an iOS Simulator, generates the project with XcodeGen, builds an unsigned Release app for real devices and uploads `Kairos-unsigned.ipa` as the run's artifact (kept 14 days).

1. Push to GitHub, open the finished run under Actions › iOS and download **Kairos-unsigned-ipa** (a zip holding the .ipa).
2. On Windows, install iTunes (or the Apple Devices app) and [Sideloadly](https://sideloadly.io). Connect the iPhone by USB and trust the computer.
3. Drag the .ipa into Sideloadly, sign in with your Apple ID and start. Sideloadly re-signs the app with your own certificate.
4. On the iPhone: Settings › General › VPN & Device Management › trust your Apple ID. iOS 16+ also needs Settings › Privacy & Security › Developer Mode on (one restart).

A free Apple ID signs for 7 days (re-sideload weekly, max 3 apps); a paid developer account signs for a year. The bundle id `app.kairos.ios` may be rewritten by Sideloadly; the app does not depend on it.

## Try it against your desktop library

```sh
python sync_server.py              # on the PC: prints the PIN and the kairos://pair link
```

In the desktop app: **Settings › Advanced › iPhone sync**. Turn on the switch, then press **Pair iPhone…** to get the QR code and the 6-digit PIN (valid 120 s). Let Windows Firewall allow Kairos on private networks. Without the desktop UI, `python sync_server.py` prints the same link; paste it into the app's pairing screen.

Offline maps: packs downloaded from the desktop land in `Documents/Maps`. Any `.mbtiles` copied into the app's Documents through Finder (USB) or the Files app is picked up the next time the app becomes active.

## Rules

- `KairosCore` stays free of UI. Anything that touches the desktop contract has a fixture-backed test.
- Changing a wire field, the edit math, the crop tool or the map clustering means regenerating the fixtures (`KAIROS_REGEN_FIXTURES=1 python -m pytest test_ios_sync.py test_ios_phase2_contract.py`) and updating the Swift side in the same commit. The pin fixture runs `map_vault.html`'s own JS in node.
- Maps stay free and offline-first: MapLibre with MBTiles packs from the desktop. No paid tile APIs.
